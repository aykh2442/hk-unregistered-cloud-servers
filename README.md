## 香港免备案云服务器的速度差距，主要出在回程线路上

决定体验的是数据从服务器回到大陆用户手里时走哪条骨干网，机房位置本身影响有限。普通国际 BGP 在大陆方向依赖 163/169 骨干加商业对等互联，这些互联带宽在晚高峰被大量挤占，延迟和丢包都会明显上升。CN2 GIA（电信）、AS9929（联通）、CMIN2（移动）属于各运营商的精品承载网，上面跑的流量少得多，高峰期表现稳定。

目标用户在东南亚、或者需要同时服务北美用户时，香港不是最优解。这是节点选择的判断依据，和产品好坏无关。

一个来自第三方测评的运营商差异值得记下来：电信用户在香港、日本、新加坡都稳；联通用户香港最好，新加坡上行断流比较明显；移动用户反而是新加坡最猛，香港和日本的上行会被 QoS 压制。如果业务是以入站流量为主（下载、视频播放），三个地区都能跑得很猛，优先选香港。
